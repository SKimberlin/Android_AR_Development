# Unity AR Android Project

This project is built using Unity with a focus on augmented reality experiences for Android devices. It leverages AR Foundation and ARCore for interactive, real-world integration.

# Overview
ARena is a multiplayer AR game where 2 players scan a marker to generate a battlefield. Using their mobile devices as a window into the fight, players will use their device to deal attacks. The game was made with the idea of it being an easy way for people to turn any location into a dynamic battle arena between friends and provide fast, replayable dueling in AR. Encouraging local multiplayer interaction and social play is another main purpose of this project.

# Tech Stack
For this project we will be using Unity 6 and utilizing GoogleARCore libraries to make our project work on android and google mobile devices. Niantic Lightship is also a technology we are using to make the multiplayer experience possible. We used quaternius.com to get some models to make the game world feel new and lessen the load on making each model inhouse. We use Microsoft Teams to communicate effectively with each team member and Trello as a way to keep track of the team’s progress. 

# Instructions
- Open the game on an Android or Google mobile device
- Make sure both players are in a lit area to make the map generation more accurate
- Make sure that only ONE player selects "Create Game" and the other selects "Join Game"
- Then both press "Start Game"
- When both characters are on screen, the players can begin battling through swipe attacks
